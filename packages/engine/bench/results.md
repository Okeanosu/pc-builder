# Engine benchmark

Generated by `pnpm --filter @pc/engine bench` (`bench/run.ts`). Synthetic catalogs from a seeded PRNG
(`syntheticCatalog(size, 7)`, category mix of the seed data, ~10% out of stock); the size column shows
total (in-stock) products. Workload per catalog: office 20M, gaming 25M, graphics 40M, ai 60M.
Each scenario is run once for warm-up, then 25× for `full` and 3× for the exhaustive
strategies; times are wall-clock per `solve()` call (domain building + search + label selection + build output).
Node limit: 2,000,000 search nodes per call.

- Machine: Apple M3 · Node v22.20.0 · 2026-11-07
- full p95 on the 250-product catalog: **11.19 ms** (target < 300 ms) → PASS
- † = at least one run hit the node limit (`stats.capped`): the strategy stopped early, so its time is bounded by
  the cap and its builds may be sub-optimal. "optimal" counts runs whose best build has the same score as `full`.
